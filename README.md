# 灵活提醒 · Flex Reminder

面向小米手机的通用可自定义 Android 提醒应用，提醒内容全部由用户自行添加。

**当前状态：需求与架构规划，尚未实现 App，也没有可安装 APK。**

## 产品目标

- 首次使用时提醒列表为空，提供“添加提醒”入口；不预置截图中的事项或专用模板。
- 提醒名称、分类、时间、频率、有效期及提示方式均由用户配置，开发不依赖用户提供个人提醒内容。
- 优先保证离线可用、提醒状态清楚、记录可追溯。
- 目标真机：小米 17 Pro Max、小米 17 Ultra 徕卡版。具体型号标识、Android 与 HyperOS 版本待真机核实。
- 第一版无需注册账号，不依赖服务器触发提醒；跨设备同步单独规划。

## 预计技术栈

Kotlin、Jetpack Compose、Room、DataStore；AlarmManager 负责需要准时的提醒，WorkManager 负责可延后的维护任务。

具体 SDK 版本、依赖版本和构建配置在工程阶段根据届时 Android 官方支持情况确定并锁定。本仓库目前不含构建工程，不能运行构建或测试。
